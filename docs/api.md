# PostinoVip — API del core

Endpoint REST/JSON del core C# (`core/src/PostinoVip.Api`), su `127.0.0.1` con `Authorization: Bearer <token>`.
Spostato da `CLAUDE.md` il 06/11/2026 (0.0.120): **aggiornare qui** quando si aggiunge o cambia un endpoint.

## Endpoint attuali

**Multi-account (dal 7a):** tutti gli endpoint di cartelle, messaggi e invio esistono anche con il prefisso `/accounts/{accountId}` (es. `GET /accounts/secondo/folders`, `POST /accounts/secondo/send`); senza prefisso agiscono sul **primo** account (compatibilità con l'app a un account). Id sconosciuto -> 404.

| Metodo e percorso | Note |
|---|---|
| `GET /version` | `{version, runtime, os}`: versione del core (Directory.Build.props), .NET, sistema operativo |
| `GET /accounts` | caselle in ordine di configurazione: `{id, name, address, configured, online, type, needsLogin}`, mai password; `online: false` = server non raggiungibile (8d); `needsLogin: true` = il fornitore OAuth2 ha rifiutato il token di rinnovo (Gmail); `cardDav: true` = rubrica sincronizzata con CardDAV (C4c); `calDav: true` = calendari sincronizzati con CalDAV (K2a) |
| `GET /folders` | cartelle con numero messaggi; `specialUse` "junk" sulla posta indesiderata in uso (J1: quella scelta nelle opzioni prevale su quella del server, che allora non lo ha); `specialUse` "archive" solo sulla cartella di archiviazione scelta (A1: quella dichiarata dal server \Archive, finché non è scelta, resta senza ruolo) |
| `GET /folders/{folder}/messages?offset=&limit=&unread=&order=` | dal più recente (`order=asc`: dal più vecchio; `unread=true`: solo da leggere; entrambi solo con la cache); `limit` 1–200; `/` nel nome cartella va codificato `%2F`; ogni voce ha anche `preview`, `hasAttachments`, `received` (3.2) e `importance` (`"normal"`, `"high"`, `"low"`, P1: da `Importance`, `X-Priority` o `Priority`) |
| `GET /folders/{folder}/conversations?offset=&limit=&unread=&order=` | conversazioni (3.6a), dalla più recente (ultima mail della conversazione in quella cartella); `items: [{id, count, unread, hasAttachments, messages: [{folder, message: {…come nella lista}}]}]`, mail dalla più recente, anche di altre cartelle dell'account (tranne Posta eliminata e Indesiderata, che aperte mostrano solo le proprie); `unread=true`: conversazioni con almeno una da leggere nella cartella; senza cache 501 |
| `GET /messages/{folder}/{uid}` | intestazioni (con `importance`, P1; `receiptTo`: indirizzo a cui il mittente chiede la conferma di lettura, solo se è il mittente stesso e la mail non è a sua volta una conferma, altrimenti null; `receiptHandled`: già `$MDNSent`, R1), `textBody`, `htmlBody` (sanificato), `hasRemoteImages`, allegati `{index,fileName,contentType}` |
| `GET /messages/{folder}/{uid}/attachments/{index}` | byte dell'allegato; tipo ricavato dall'estensione se dichiarato `application/octet-stream` |
| `GET /messages/{folder}/{uid}/raw` | il messaggio così com'è (`message/rfc822`, E1: «Salva con nome» .eml): byte originali dalla copia locale o con `BODY.PEEK[]` (non diventa letto); POP3: il file scaricato |
| `POST /eml` | apre un file .eml (E1): corpo = i byte del file (fino a 100 MB); risposta `{id, message: {…come GET /messages/{folder}/{uid}}}` (`uid` finto 1); 400 sul campo `file` se non è una mail (nessuna tra From, Date, Subject, To, Message-ID). Resta solo in memoria nel core (al massimo 20 aperti: oltre si chiude il meno usato), in sola lettura |
| `GET /eml/{id}` · `GET /eml/{id}/attachments/{index}` · `DELETE /eml/{id}` | la mail aperta, un suo allegato (una mail allegata, `message/rfc822`, si riapre con `POST /eml`), chiusura (204 anche se già chiusa); id sconosciuto -> 404 |
| `GET [/accounts/{id}]/eml/{id}/draft?mode=reply\|replyAll\|forward` | bozza precompilata dal file, come `…/messages/{folder}/{uid}/draft`; il proprio indirizzo (escluso da «Rispondi a tutti») è quello dell'account della rotta |
| `GET /messages/{folder}/{uid}/draft?mode=reply\|replyAll\|forward` | bozza precompilata, non invia; `quoteHtml` (3.7b): anteprima formattata della citazione (Da/Inviato/A/Oggetto + originale ripulito, immagini incorporate come `data:`) |
| `GET /account` | solo l'indirizzo del mittente |
| `GET /events` | Server-Sent Events di **tutti** gli account: `{type:"mailbox-changed",account,folder,count}`, `{type:"watch-status",account,connected}`, `{type:"connection-status",account,online}`, `{type:"login-status",account,needsLogin}`, `{type:"contacts-changed",account,count}`, `{type:"calendars-changed",account,count}` (K2a: la sincronizzazione CalDAV ha cambiato i calendari, o serve la conferma della prima volta) (C4b: la sincronizzazione CardDAV ha cambiato la rubrica sul computer, o serve la conferma della prima volta: l'app la rilegge), `{type:"folder-synced",account,folder}` (11/11/2026: il download in background ha completato le intestazioni di una cartella alla prima sincronizzazione o lasciate dalla lista: l'app rilegge la lista se è aperta lì), `{type:"headers-pending",account,folder}` (per il core: la lista ha scaricato solo le 200 intestazioni nuove più recenti; l'app lo ignora) (all'iscrizione gli ultimi stati di ogni account); `: ping` ogni 30 s |
| `GET/POST [/accounts/{id}]/contacts` · `GET/PUT/DELETE …/contacts/{cid}` | rubrica dell'account, solo sul computer (C1): `{id, name, givenName, familyName, displayName, emails:[{address,label}], phones:[{number,label}], company, notes, updated}`; errori 400 per campo (`emails`, `contact`…) |
| `POST …/contacts/import` · `GET …/contacts/export?format=vcf\|csv` | importa `{format, data(base64)}` → `{imported, duplicates, invalid}`; esporta il file |
| `GET [/accounts/{id}]/contacts/sync` | stato della sincronizzazione CardDAV (C4b): `{enabled, state, lastSync, error, needsConfirmation, pendingUpload, addressBook}`; `state`: `off` (non attiva per l'account), `waiting`, `syncing`, `ok`, `offline`, `error`, `unavailable` (account OAuth2 o senza password); `needsConfirmation`: ci sono `pendingUpload` contatti solo sul computer da caricare dopo la conferma (2a) |
| `POST …/contacts/sync` · `POST …/contacts/sync/confirm` | sincronizza subito (202); **modifica la rubrica del server**: conferma il caricamento dei contatti solo sul computer (202, la sincronizzazione parte subito); sincronizzazione non attiva -> 409 |
| `POST /account/test-carddav` | «Verifica rubrica» (C4c): `{email, password, host (server di ricezione), url?, certificateSha256?}` → `{ok, error, addressBook, url}` (200 anche se non riesce); sola lettura (PROPFIND), non salva nulla; password mancante -> 400 sul campo `password`. Account con OAuth2 (C4d, solo Google): `{email, host, oauthProvider, refreshToken, url?}` al posto della password, scoperta da `https://www.googleapis.com/.well-known/carddav` con il token di accesso (Bearer) |
| `POST /account/test-caldav` | «Verifica calendario» (K2a): stesso corpo di `test-carddav` → `{ok, error, calendars:[nomi]}` (solo i calendari che accettano appuntamenti); sola lettura, non salva nulla; con OAuth2 (G1, solo Google) `{email, host, oauthProvider, refreshToken, url?}`, scoperta da `https://apidata.googleusercontent.com/caldav/v2/<email>/user` |
| `GET /oauth/providers` | fornitori OAuth2 `{id, name, configured}` (senza client ID l'app non mostra il pulsante) |
| `POST /oauth/start` | inizia un accesso: `{provider, loginHint?, contacts?, calendar?}` → `{id, authorizationUrl}` da aprire nel browser; `contacts: true` (C4d) chiede anche il permesso dei contatti (Google: `https://www.googleapis.com/auth/carddav`, cambiabile con `OAuth:Google:ContactsScope`); con un fornitore senza CardDAV -> 400 sul campo `contacts`; `calendar: true` (G1) chiede anche il permesso del calendario (Google: `https://www.googleapis.com/auth/calendar`, cambiabile con `OAuth:Google:CalendarScope`), senza CalDAV -> 400 sul campo `calendar` |
| `GET /oauth/flows/{id}` | stato dell'accesso `{id, provider, status (pending/done/error), email, refreshToken, error, servers, contacts, calendar}`; il token di rinnovo si consegna una volta sola; `contacts` / `calendar`: permesso dei contatti / del calendario concesso (null se non chiesto) |
| `DELETE /oauth/flows/{id}` | annulla l'accesso in corso |
| `GET /oauth/callback` | ritorno del browser dal fornitore (unico endpoint senza token: vale lo «state») |
| `GET [/accounts/{id}]/calendars` | calendari dell'account (K2a), il primo è il predefinito: `{items:[{id, name, synced, count, readOnly}]}` (`readOnly`, G2: di sola lettura sul server, es. festività di Google: crea, modifica ed elimina rispondono 409); senza CalDAV uno solo, «Calendario», sul computer; senza cache 501 |
| `GET …/calendars/sync` · `POST …/calendars/sync` · `POST …/calendars/sync/confirm` | come per i contatti (stato, sincronizza subito, **conferma il caricamento** degli appuntamenti solo sul computer: modifica i calendari del server); `addressBook` = nome del calendario o «N calendari»; non attiva -> 409 |
| `GET …/calendars/events?from=&to=&calendars=` | occorrenze di [from, to) (istanti ISO 8601 con fuso; al massimo 400 giorni e 5000 occorrenze, poi `truncated`) nei calendari indicati (id separati da virgole; assente = tutti), ricorrenze espanse con le eccezioni (K2b): `{items:[{calendarId, eventId, uid, recurrenceId, start, end, allDay, summary, location, recurring, reminderMinutes}], truncated}`; orari in UTC («…Z»), giornata intera come date comprese; comprese le occorrenze iniziate fino a 31 giorni prima e ancora in corso; calendario sconosciuto 404, istanti non validi 400 |
| `GET …/calendars/{cal}/events/{id}` | la serie: `{id, calendarId, uid, summary, location, description, start, end, allDay, timeZone, reminderMinutes, recurrence:{frequency, interval, days, monthDay, week, month, count, until}\|null, customRecurrence, exceptions, attendees}`; ora locale «aaaa-mm-ggThh:mm» nel fuso `timeZone`, giornata intera con date comprese; `customRecurrence` = RRULE che la finestra «Ricorrenza» non sa mostrare |
| `POST …/calendars/{cal}/events` · `PUT …/calendars/{cal}/events/{id}` · `DELETE …/calendars/{cal}/events/{id}` | **modifica** il calendario (con CalDAV poi anche il server): crea (201) / modifica la serie / elimina la serie (204); corpo `{summary, location, description, start, end, allDay, timeZone?, reminderMinutes?, recurrence?, keepRecurrence}` (fuso assente = quello del computer; `keepRecurrence`: ricorrenza, eccezioni comprese, invariate); la modifica cambia solo questi campi nel testo esistente, il resto resta; inizio o ricorrenza cambiati -> eccezioni tolte; errori 400 sui campi `start`, `end`, `timeZone`, `recurrence`, `reminderMinutes`, `summary`, `location`, `description` |
| `GET` · `PUT` · `DELETE …/calendars/{cal}/events/{id}/occurrence?recurrenceId=` | una sola occorrenza di una serie (K4a; `recurrenceId` come nelle occorrenze del periodo): dettaglio (quella modificata, o la serie con l'ora dell'occorrenza; `recurrenceId` nella risposta); **modifica** solo questa (VEVENT con RECURRENCE-ID, nuova o la stessa; stesso corpo della serie, ricorrenza ignorata); **elimina** solo questa (EXDATE nella serie, tolta l'eventuale modifica), 204; appuntamento non ricorrente -> 409; `recurrenceId` mancante 400 |
| `POST /accounts/{id}/receive` | Invia/ricevi (F9, 4.2c): per un POP3 controlla subito il server; con CardDAV attivo sincronizza anche la rubrica (C4b), con CalDAV i calendari (K2a); 202; id sconosciuto 404 |
| `GET /addresses/suggest?q=&limit=` · `DELETE /addresses/recent?address=` | completamento degli indirizzi da contatti e recenti di tutti gli account; la ✕ |
| `GET /search?q=&folder=&offset=&limit=` | ricerca nella cache locale (8c), estratto con parole tra U+0002/U+0003 |
| `GET /search/server?q=&folder=` | ricerca sul server per le mail con corpo non in cache (8c-3) |
| `GET /cache/orphans` | dati locali di account non più configurati `{id, name, address, sizeBytes}` (8e-2) |
| `DELETE /cache/orphans/{id}` | **elimina dal computer** quei dati (204); account configurato -> 409 |
| `POST /accounts/{id}/cache/rebuild` | svuota la copia locale dell'account e la fa riscaricare (202, evento `cache-rebuilt`) |
| (qualsiasi) | **503 "Non connesso"** se il server della casella non è raggiungibile (8d) |
| `POST /drafts` | **modifica** (3.8): `{…come /send senza saveCopy, replace?:{uid?, localId?}}` salva in Bozze (`\Drafts`, `\Draft`) al posto di `replace`; destinatari facoltativi; senza connessione resta sul computer: `{folder, uid, pending, localId}` |
| `GET /outbox` · `DELETE /outbox/{id}` · `POST /outbox/{id}/send` · `POST /outbox/{id}/to-drafts` | Posta in uscita del computer (3.8): elenco `{id, subject, to, created, sendAfter, error}`; elimina (non verrà inviata); "Invia ora" (202); torna in Bozze (**modifica**); senza cache 501 |
| `GET /messages/{folder}/{uid}/compose` | bozza da riaprire (3.8): `{to, cc, subject, html, text, inReplyTo, references, quoteHtml, attachments, bcc, importance, readReceipt}`, non modifica nulla |
| `POST /send` | `{to:[], cc:[], subject, body, inReplyTo?, references:[], saveCopy, attachments:[{fileName, contentType?, data(base64)}], forwardAttachments?:{account?, folder, uid, indexes} | {eml, indexes}, htmlBody?, quote?:{account?, folder, uid, mode} | {eml, mode} | {html}, sendAfter?, deleteDraft?:{uid?, localId?}, importance?: "normal"|"high"|"low", readReceipt?: bool}` (`importance`, P1: alta o bassa scritta come Outlook, `Importance` e `X-Priority`; `account`: casella del messaggio originale, se diversa dal mittente; `htmlBody` (3.7b): testo formattato, la mail diventa HTML + testo con `body` come versione in testo, HTML ripulito dal core, immagini `data:` incorporate; `quote`: il core riprende l'originale e aggiunge in fondo la citazione in testo e in HTML, `mode` non valido -> 400 sul campo `quote`) — **invia davvero**; `saveCopy` (falso se omesso) fa APPEND in Posta inviata; risposta `{serverResponse, savedTo?, saveError?}`; con `sendAfter` futuro o server di invio non raggiungibile la mail va nella **Posta in uscita** del computer (3.8): `{queued: true, outboxId, sendAfter, offlineQueued}`; `deleteDraft`: bozza eliminata dopo l'invio (o subito, se messa in coda con la connessione) |
| `POST /messages/{folder}/{uid}/receipt` | `{send: bool, automatic?: bool}` (R1) — con `send` **invia davvero** la conferma di lettura (RFC 8098: `multipart/report; report-type=disposition-notification`, oggetto «Letto: …», `Disposition` manual-action o, con `automatic`, automatic-action) al mittente; in ogni caso **modifica** la casella (STORE +`$MDNSent`, RFC 3503). 409 se la mail non chiede la conferma al suo mittente, se sta in Posta indesiderata, Posta inviata o Bozze, o se è già `$MDNSent` (noto con la copia locale); risposta `{sent}` |
| `GET /junk` | opzioni posta indesiderata dell'account (J1): `{level: None/Low/High/SafeListsOnly, folder (scelta, null = nessuna), junkFolder (in uso: scelta, del server \Junk o dal nome; null = nessuna), trustContacts, safeSenders, safeRecipients, blockedSenders}`; voci `nome@dominio` o `@dominio`, minuscole; senza copia locale 501 |

| `GET /messages/{folder}/{uid}/ignored` | `{ignored}` (C1): la conversazione della mail è ignorata; sola lettura; senza copia locale 501 |
